# Rank badge fix, analytics dashboard, and UX polish (v2)

This change fixes a silent ranked-data failure, adds animated rank badges, skeleton loading, toast notifications, client-side match filters, champion performance analytics (stats table, pie chart, line chart via recharts), and champion splash art backgrounds on match cards. The v1 review surfaced six issues; all have been addressed: toast cap at 5, filter callbacks simplified, aria-live on filter count, analytics labeled "Based on all loaded matches", splash art URL extracted from the champion icon URL, and shimmer animation kept intentional for Diamond+.

**Watch for:** The recharts tooltip hardcodes dark-mode colors rather than respecting the CSS custom properties used elsewhere, so light-mode tooltips render with dark backgrounds (likely). Pie chart labels overlap on mobile when many game modes are present (likely).

**Verdict**: APPROVED

## High-level view

The ranked error path is now properly surfaced: the API route captures the error detail and returns it as `rankedError`, and the Dashboard renders it inline only when no ranked entries exist.

The toast system is capped at 5 concurrent notifications, evicting the oldest when exceeded.

Match filtering applies client-side via a memoized filter function. The analytics section now carries a "Based on all loaded matches" subtitle, clarifying that it operates on the full dataset regardless of active filters.

The tooltip styling across all three recharts charts uses hardcoded dark-mode hex colors, which will appear jarring on light backgrounds.

## Tooltip theming mismatch

All chart tooltips hardcode a dark color scheme:

```typescript
contentStyle={{
  backgroundColor: "#1f2937",
  border: "1px solid #374151",
  borderRadius: "8px",
  color: "#f3f4f6",
}}
```

The app uses a class-based dark mode toggle (`.dark` on `<html>`). Since recharts tooltips don't participate in Tailwind's dark variant, the tooltip renders with gray-800 background regardless of the page's theme. In light mode this produces a floating dark card against white surroundings. A fix would be to read the current theme from context and swap the color values, or to render a custom tooltip component styled with Tailwind classes.

## Pie chart label density

The `RoleDistribution` pie chart uses a render function for labels:

```typescript
label={({ name, payload }) => {
  const pct = (payload as GameModeDistribution)?.percentage ?? 0;
  return `${name} ${pct}%`;
}}
```

With `labelLine={false}` and 5-8 segments (Ranked Solo, Ranked Flex, Normal Draft, Normal Blind, ARAM, etc.), the text labels are positioned at the centroid of each arc. At the 264px chart height on mobile, arcs under ~15% produce labels that visually collide, degrading readability on phones.
